# Flavia Garcia Architects — Vitrine

Página de apresentação do tema WordPress desenvolvido para o escritório de arquitetura e interiores Flavia Garcia Architects.

O código do tema fica em um repositório privado; aqui está apenas a vitrine pública do projeto.

## Ver a página

Com o GitHub Pages ativado (Settings → Pages → Deploy from a branch → `main` / `root`), a vitrine fica disponível em
`https://tigos88.github.io/flaviaGarcia-P/`.

Para abrir localmente, basta abrir o `index.html` no navegador.
